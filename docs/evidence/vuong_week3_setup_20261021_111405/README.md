# Chỉ mục chuẩn bị tuần 3 — Bước 1

Đây là bằng chứng chuẩn bị Git/hồ sơ, không phải phiên kiểm thử hoặc kết quả nghiệm thu.

- `preparation.json`: ngày giờ, SHA, nhánh và kết quả chuẩn bị; các runtime chưa xác minh.
- `preserved_week2_sha256.json`: danh sách và hash 58 file bằng chứng cũ, chỉ dùng xác nhận bảo toàn, không tái sử dụng làm bằng chứng đạt tuần 3.
- `SESSION_TEMPLATE.json`: mẫu cho phiên chạy mới, chưa có kết quả thực thi.
- `verification.json`: kết quả rà hồ sơ và so sánh hash sau chuẩn bị (được bổ sung sau).

Hồ sơ chính: [VUONG_WEEK3_ACCEPTANCE.md](../../VUONG_WEEK3_ACCEPTANCE.md).
Không chứa JUnit, audit hoặc ảnh nghiệm thu mới vì chưa thực hiện Bước 2–3.
