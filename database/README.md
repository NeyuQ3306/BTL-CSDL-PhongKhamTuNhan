# SQL của nhóm

Thư mục này dành cho yêu cầu 2, chưa có SQL triển khai tại commit khởi tạo.

Thứ tự bàn giao: `schema.sql` (11 bảng), `constraints.sql` (ràng buộc bổ sung nếu cần), `seed.sql` (dữ liệu giả), `queries.sql` (Q1–Q4), `expected_results.md` (đáp án), `project1_submission.sql` (gộp cuối tuần 3).
